# Obrona Zamku

Gra tower defense w przeglądarce o obronie średniowiecznego zamku przed wrogimi rycerzami.

**Zagraj:** https://szumickip.github.io/obrona-zamku/

## Co jest w grze

- Kampania z 3 planszami: Królewski Gościniec, Stary Bród (dwie drogi i rzeka), Zimowa Przełęcz.
- 4 rodzaje wież (łucznicy, kusznicy, katapulta, wrząca smoła), każda z 3 poziomami.
- Wrogowie: giermkowie, rycerze piesi i konni, ciężkozbrojni, tarany oblężnicze i Czarny Lord.
- Umiejętności dowódcy: Deszcz strzał (Q) i Róg wojenny (W).
- Profile graczy, gwiazdki za plansze i automatyczny zapis postępu w przeglądarce.

## Sterowanie

- Kliknij kamienne miejsce przy drodze, żeby zbudować wieżę.
- Kliknij wieżę, żeby ją ulepszyć albo sprzedać.
- Spacja: pauza · N: następna fala · Q / W: umiejętności · Esc: anuluj.

Cała grafika jest rysowana kodem (canvas), bez zewnętrznych obrazków. Wystarczy otworzyć `index.html`.
